# Demo Script

## 0:00-0:30

Show FinSecure payment API latency above 5 seconds.

## 0:30-1:15

Commander captures a plan and delegates narrow scopes.

## 1:15-2:00

Diagnostic reads poisoned logs and incorrectly decides to restart the payment service.

## 2:00-2:45

Diagnostic attempts the unauthorized restart. Show the denial and emphasize that the MCP tool did not execute.

## 2:45-3:15

Explain that the demo is not about detecting the word "restart." The agent was influenced, but its authority was unchanged.

## 3:15-4:00

Remediation performs an authorized staging restart.

## 4:00-5:00

Close with: The agent was compromised. The authorization was not.
